# Data Directory

This directory is structured to hold the datasets used by the SolarCast ML pipeline.

## Directory Structure
- `data/sample/`: Contains synthetic, generated magnetogram arrays. **These are for software testing only.**
- `data/raw/`: (Not tracked by git) Should contain raw FITS files downloaded from JSOC.
- `data/processed/`: (Not tracked by git) Should contain preprocessed, ML-ready NumPy arrays or PyTorch tensors.

## Synthetic Data Warning
The `data/sample/` directory contains synthetic data generated by `scripts/generate_sample_data.py`. This data does not represent real physics and cannot be used to train a scientifically valid model. It exists solely to allow developers to run the pipeline, test the backend API, and view the frontend without downloading gigabytes of real astronomical data.

## Obtaining Real Data
To train a real model, you must download SDO/HMI data from the Joint Science Operations Center (JSOC).
1. Register at http://jsoc.stanford.edu/
2. Use the `drms` Python library to query the `hmi.sharp_cea_720s` data series.
3. Refer to `docs/dataset.md` for detailed instructions on acquiring and labeling the data.

## File Format Convention
Preprocessed files should ideally be saved as `.npy` or `.pt` files.
Naming convention: `AR<NOAA_NUMBER>_<TIMESTAMP>_label<0_or_1>.npy`
Example: `AR11158_20110214_120000_label1.npy`
